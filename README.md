# InviteMe

SaaS-приложение для создания цифровых приглашений (свадьбы, дни рождения, вечеринки) с тарифами Free и Pro. Интерфейс на русском и английском.

## Стек

Next.js 15 (App Router) · TypeScript · Tailwind CSS v4 · Prisma + SQLite · Better Auth (email/пароль) · next-intl · Zod · next/og (серверный PNG).

## Запуск

```bash
npm install
cp .env.example .env        # задайте BETTER_AUTH_SECRET
npx prisma migrate dev      # создаёт prisma/dev.db и запускает seed шаблонов
npm run dev                 # http://localhost:3000
```

Повторно заполнить шаблоны: `npm run db:seed`. Полный сброс базы: `npm run db:reset`.

## Тарифы

| | Free | Pro ($4.99/мес) |
|---|---|---|
| Шаблоны | 3 базовых | все 14, включая премиум |
| Приглашения | до 3 | без ограничений |
| Шрифты / палитры | 3 / 3 базовых + фирменные шрифт и палитра шаблона | все 21 / 17 |
| Скачивание PNG | с водяным знаком | без водяного знака |
| Повторное редактирование сохранённого | нет (только просмотр и скачивание) | да |

## Шаблоны

14 шаблонов в двух направлениях дизайна. У каждого своя композиция, декор, сочетание шрифтов и палитра:

- **Artistic Romantic** (`src/templates/romantic.tsx`): акварельные цветы и размывы, ботанические иллюстрации, фактура бумаги, сургуч, тонкая линейная графика. Элегантная свадьба, Цветочная романтика, Садовый праздник (гербарий), Бохо-арка, Классическое приглашение (конверт с сургучом), Беби-шауэр, Звёздная ночь.
- **Modern Art Direction** (`src/templates/modern.tsx`): крупная типографика, геометрия, контрастные цвета, журнальные и плакатные композиции. Журнальная обложка, Большой день рождения, Мемфис-поп, Баухаус-вечеринка, Ретро-вечеринка, Гала в стиле ар-деко, Роскошное золото.

Общие элементы лежат в `src/templates/kit.tsx` (текст, сетка, подгонка размеров) и `src/templates/art.tsx` (SVG-фильтры акварели и бумаги, цветы, листья, геометрические и графические элементы). Направление каждого макета, фиксированные шрифты основного текста и акцентов задаются в `src/templates/types.ts`.

| Бесплатные | Pro |
|---|---|
| Элегантная свадьба, Большой день рождения, Журнальная обложка | Цветочная романтика, Роскошное золото, Бохо-арка, Звёздная ночь, Садовый праздник, Мемфис-поп, Баухаус-вечеринка, Ретро-вечеринка, Гала в стиле ар-деко, Беби-шауэр, Классическое приглашение |

Один и тот же компонент `InvitationCard` рисует превью в галерее, живое превью в редакторе и PNG-экспорт, поэтому при редактировании текста дизайн сохраняется. Фирменные шрифт и палитра шаблона всегда доступны, даже если в общем списке они относятся к Pro.

Правила описаны в `src/lib/plans.ts`. Проверки выполняются на сервере в `src/lib/plan-guard.ts` и вызываются из Server Actions (`src/actions/`), страницы редактора и маршрута экспорта `src/app/api/invitations/[id]/export`. Замки и окна в интерфейсе только отражают эти правила.

## Демонстрация подписки

1. Зарегистрируйтесь: новый пользователь получает тариф Free.
2. Создайте приглашение из бесплатного шаблона, отредактируйте и сохраните его.
3. Попробуйте премиум-шаблон, премиум-шрифт или палитру, четвёртое приглашение или повторное редактирование — появится предложение перейти на Pro.
4. Перейдите на `/checkout`. Страница помечена как **ТЕСТОВЫЙ РЕЖИМ**: платёжная система не подключена, деньги не списываются, данные карты не отправляются на сервер. Введите `4242 4242 4242 4242`.
5. Сервер создаёт запись `Subscription` с `isTest = true` и меняет `User.plan` на `PRO`. Тариф читается из базы при каждом запросе, поэтому сохраняется после обновления страницы.
6. Чтобы показать сценарий заново, нажмите в личном кабинете «Вернуться на Free (демо)».

## Структура

```
prisma/              схема, миграции, seed
src/app/[locale]/    страницы: главная, templates, editor/[id], invitations/[id], dashboard, pricing, checkout, login, register
src/app/api/         auth (Better Auth), экспорт PNG
src/actions/         Server Actions: приглашения, подписка
src/lib/             auth, prisma, plans, plan-guard, design (шрифты и палитры)
src/templates/       каталог, 14 макетов (romantic.tsx, modern.tsx), библиотека SVG-иллюстраций (art.tsx, kit.tsx) и общий компонент карточки (превью и PNG)
src/messages/        переводы ru / en
```

Экспорт PNG загружает нужные символы шрифтов из Google Fonts, поэтому серверу нужен доступ в интернет.
